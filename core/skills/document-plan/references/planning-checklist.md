## Planning checklist (before Write)

- [ ] Language asked and recorded
- [ ] Overview reflects detected stack (not a template from another company)
- [ ] Each step has deliverable path, tasks, acceptance
- [ ] **Kind** set when useful: `new` (one step per new file) / `update` (prefer one coalesced step) / `refactor`
- [ ] No 5–12 tiny baby-steps by default — fewer, larger steps
- [ ] No external work-item URLs required
- [ ] **new** steps fit one `document-implement` session; **update** may touch multiple existing paths in one session
