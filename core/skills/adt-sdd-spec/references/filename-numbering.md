## Canonical PRD location and useful filename

Place PRDs under the feature/story `PRD/` folder from the active manifest or storage contract. Classic defaults to `US01` when no story is specified; global paths use the repository's configured feature root.

Prefer a readable filename and reuse a feature identifier/sequence when the repository already uses one. Filename sequence and slug are navigation conventions; do not block equivalent content over a title or numeric naming difference. Avoid creating duplicate files when an existing PRD is the correct owner.
