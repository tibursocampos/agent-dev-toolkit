# adt-sdd-develop validation commands

Classic `adt-sdd-develop` does not write or validate SESSION gates and does not acquire PLAN claims. Do not invoke session or ledger scripts as prerequisites for implementation, step completion, or cadence continuation.

Run only the repository and stack validation that is relevant to the approved PLAN step. Prefer commands already documented by the project and record the command/result in that step's single PLAN progress row. `references/optional-flows.md` describes separate user-requested closeout actions.
