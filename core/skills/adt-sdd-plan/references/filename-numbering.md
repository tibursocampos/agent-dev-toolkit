## PLAN location and naming

Use the canonical feature/story PLAN location described by `STORAGE.md`, normally alongside the source PRD under `features/NNN-slug/USnn/PLAN/` (or `TSnn`). If the PRD has an identifier, reusing it in the PLAN filename and portable PRD link makes navigation easier. Global feature paths follow the manifest-resolved root.

Example:

```text
features/002-exportacao-perfil/US01/PLAN/PLAN_002_exportacao_perfil_usuario.md
```

Keep new paths portable in written artifacts. A filename or title convention helps organize work; it does not determine whether the PLAN's substantive content is usable. Resolve a material path conflict before writing to the wrong canonical destination.
