## Focused post-step review (optional)

O3 has no universal verifier after every implementation step. Request a read-only specialist review only when a concrete risk remains that the implementer result and relevant evidence do not resolve, such as a material security, data, architecture, or integration boundary.

Keep the review narrow: identify the exact changed behavior, risk, and acceptance boundary. The reviewer reports evidence and findings; it does not change the PLAN, implement fixes, or authorize the next step. The parent reconciles any finding with the approved PLAN and requests a decision only when the finding requires a material change.

If no concrete risk calls for an additional review, continue with the ordinary parent reconciliation. Do not use a preference flag or verifier receipt as a progress state or authorization gate.
