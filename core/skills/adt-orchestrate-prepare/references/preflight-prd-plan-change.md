## Optional PRD/PLAN diagnostics

The former PRD-to-PLAN-to-CHANGE preflight is retired. The legacy PRD and PLAN diagnostics describe older document formats and are available only for an explicit request to inspect one of those formats. Review current artifacts against their behavior, dependencies and evidence.

For a relevant discrepancy, inspect the current canonical artifacts and evidence, identify the affected behavior or plan, and route the correction to the owner (`adt-sdd-spec` for PRD, `adt-sdd-plan` for PLAN). Keep unrelated stories eligible. If resolving the issue materially changes the implementation outcome or scope, present the updated PLAN for a new decision before implementation.

Legacy scripts and fixtures remain for compatibility. They do not establish current document readiness.
