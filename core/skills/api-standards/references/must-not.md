# Must not (api-standards)

* Embed company, vendor, or product-specific API contracts, naming schemes, media types, or branding in Core playbooks.
* Generate typed clients, DTOs, or SDK wrappers — that is `api-integrate`.
* Paste unretracted secrets, tokens, `.env` values, or production payloads into references or chat examples.
* Dump entire `memory-bank/` trees or full PRD/OpenAPI documents into the session (`SR-NO-FULL-DUMP`).
* Pretend agnostic guidance overrides an existing, documented consumer-repo standard without operator confirmation.
