## Storage and `.gitignore` (plan skill)

If PRD is global, PLAN is global unless the user chooses repository storage. Before `Write` in **repository** mode, follow `STORAGE.md` § Repository mode - `.gitignore` and `STORAGE-RESOLUTION.md`: resolve the manifest and read `features_versioned` and apply the matching SDD block (see `sdd-spec/references/storage-gitignore.md`). Update manifest (`artifact_language`, `features_versioned`, folders). Do **not** write or update PLANs at repo-root `PLAN/`. **Global** mode: do not edit `.gitignore`.
